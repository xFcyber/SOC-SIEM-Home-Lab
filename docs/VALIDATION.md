# Preparation checks and limits

Repository preparation includes checking local document links, paired Markdown fences, archive contents and sample field positions for the IPv4 TCP parser.

The parser layout was compared with official Netgate documentation. Synthetic test events validate field positioning only; they are not evidence from the author's lab and are not bundled as incident data.

No live VM, Splunk search, Wazuh collection or scheduled alert was accessed or executed during preparation. Current configurations, installed versions, event measurements and screenshots must be confirmed in the lab.
